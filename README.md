# 屏码传 · 屏幕二维码离线传输工具

一个**纯前端、零安装、完全离线**的文件传输工具：电脑屏幕以**流式多二维码阵列**显示文件数据，手机用摄像头扫描即可实时接收并还原文件。数据不经过任何服务器。

**交付物**：`screen-qr-transfer.html`（单个可直接运行的完整 HTML 文件，全部依赖已内联）。

---

## 快速开始

### 发送端（电脑）
1. 用 Chrome / Edge 打开 `screen-qr-transfer.html`（双击即可，file:// 也能用）。
2. 选择文件（可拖拽）。
3. 选速度档位：**稳定 / 标准 / 高速**。
4. 点「▶ 开始发送」——屏幕全屏显示 3×2 二维码阵列，边框颜色逐帧变化。
5. 可先用「📐 对齐测试」让手机确认能看到全部码位。

### 接收端（手机）
手机浏览器打开**同一个页面**，二选一：
- **方式 A（推荐）**：双击 `启动局域网服务.bat`，手机连同一 Wi-Fi，在浏览器打开提示的 `http://<电脑IP>:8000/screen-qr-transfer.html`。
- **方式 B（完全离线）**：把 `screen-qr-transfer.html` 通过微信/QQ/数据线发给手机，用浏览器打开（Android Chrome/Edge 可直接用；iOS 建议用方式 A，因 iOS 对 file:// 调用摄像头有限制）。

然后：切到「📷 接收端」→ 开启摄像头 → 对准电脑屏幕 → 等进度到 100% → 保存文件。

### 对准技巧
- 手机距屏幕 30~60cm，保持稳定；避免反光与强背光；屏幕亮度适中。
- 绿框=该码位正常，黄=偶发失败，红=连续失败（会自动重新定位）。

## 设计说明：为什么这样实现「多维视觉编码」

需求中的「含颜色变化的多维视觉编码」中，**逐模块彩色二维码在真实手机摄像头上不可靠**（白平衡/增益不稳定，色彩极易漂移误判）。本工具采用同样多维、但可稳定解码的方案：

1. **空间维度**：单帧并行 **6 个二维码**（3×2 阵列），单帧承载量约为单码的 6 倍。
2. **时间维度**：流式换帧；每包独立 **CRC32** 校验；发包顺序**每轮洗牌**，避免某码位长期失败导致特定数据包永远收不到；漏帧/漏码只损失该包，靠后续轮次重发补齐；小文件的数据包也会循环重发。
3. **颜色维度**：边框颜色逐帧变化（红→绿→蓝→黄循环）作为**帧同步标识**，不承载数据——颜色只做视觉与同步用途，因此解码稳定。
4. **可靠性关键**：所有包（含元数据）补齐为相同负载长度 → 同屏同一版本、统一尺寸；二维码以**整数模块像素**渲染（模块均匀锐利，jsQR 解码稳定）；元数据包**每帧固定占用 0 号码位**，接收端只要锁住 0 号就能立即拿到文件信息、显示进度。

### 传输协议（每包 = 一个二维码）
```
[0]    magic 0x53
[1]    协议版本 0x02
[2]    flags（bit0 = 元数据包）
[3]    cell：当前显示所在码位（0-5），发送端逐帧按槽位改写；
          接收端据此建立「码位 ↔ 屏幕位置」对应，抗透视/偏移
[4-7]  包序号 uint32 BE（0 = 元数据，≥1 = 数据）
[8-11] 总数据包数 uint32 BE
[12-13] 负载长度 uint16 BE
[14-17] 负载 CRC32 uint32 BE
[18+]  负载：元数据 = JSON（\0 结尾、补齐到 chunkSize）；数据 = 定长分块
```
- 接收端：整帧定位种子码 → 收集「码位 ↔ 位置」对应 → **仿射拟合**修正透视/偏移 → 逐码位验证锁定（包内码位号校验几何正确性）→ 每码位独立裁剪解码 → 包去重 → 收齐后重组 + 整文件 CRC 校验 → 自动保存。码位未锁满前每 3 秒自动重新定位。

### 兼容性
- 发送端：任意可运行 Canvas 的现代浏览器（Chrome/Edge/Firefox）。
- 接收端：需要 `getUserMedia` 摄像头权限（Chrome/Edge/Safari 均可；需 HTTPS、`127.0.0.1` 或 file:// 等安全上下文）。
- 使用**打了补丁的 jsQR**（见下），支持同一画面内多二维码识别。

### jsQR 补丁说明
jsQR 1.4.0 原版对同一画面多个二维码只会尝试**得分最高的一组**三点（查找模式），密集码阵下极易选错组合导致整体返回空。补丁：
1. 先按得分截取候选查找模式（过滤数据区误报）；
2. 按**几何关系（直角 + 等臂）**组合三点，生成多组候选；
3. 逐组尝试解码直到成功。
补丁位置 `dev/lib/jsqr.js` 的 `locate()` 函数，注释以 `[屏码传补丁]` 标记。
